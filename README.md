# Посмотри в окно

Учебный проект Яндекс Практикума: CSS-вёрстка приложения для просмотра видео из разных городов.

Репозиторий: https://github.com/VVictorias/posmotri-v-okno-ad

Для запуска откройте `index.html` через локальный HTTP-сервер. Поиск и видеоролики загружаются из API, указанного в исходном скрипте проекта.
